# Python Libraries  
This Github repo. will cosist all the libraries that are mentioned below.

**1. Data Science & Analysis**

- **NumPy:** Handles large, multi-dimensional arrays and matrices, providing high-performance mathematical operations.
- Link :- https://www.youtube.com/watch?v=CpPLLp3snK4&list=PLKnIA16_Rmvb-ToL3RQ_bwxG4_ND-0-DT
- **Pandas:** Offers flexible data structures like DataFrames to clean, manipulate, filter, and analyze structured tabular data.
- Link :- https://www.youtube.com/watch?v=kq9Vmg5d7Sk&list=PLKnIA16_RmvbR85fgbfVRKOiMokUKVupy
- **SciPy:** Built on NumPy; used for advanced scientific computations including integration, optimization, and signal processing.
- **Statsmodels:** Focused heavily on statistical modeling, hypothesis testing, and time-series forecasting.

**2. Data Visualization**
 - Link :- https://www.youtube.com/watch?v=-jTD74eEy2I&t=1813s
- **Matplotlib:** The foundational library for creating static, animated, and interactive visualizations.
- **Seaborn:** Built on top of Matplotlib; provides beautiful, high-level statistical graphics with minimal code.
- **Plotly:** Used to build highly interactive, web-ready graphs and complex analytical dashboards.

**3. Web Scraping & Automation**

- **Requests:** Simplifies making HTTP requests to interact with web APIs and pull raw HTML data.
- **BeautifulSoup:** Parses HTML and XML documents to easily extract specific pieces of data from web pages.
- **Scrapy:** A powerful, scalable framework designed for large-scale web crawling and data mining.
- **Selenium:** Automates web browsers to simulate real user actions, useful for testing web applications and scraping JavaScript-heavy sites.

**4. Machine Learning & Artificial Intelligence (AI)**

- **Scikit-learn:** The go-to tool for traditional machine learning algorithms like classification, regression, clustering, and data preprocessing.
- **TensorFlow:** An open-source, production-ready framework developed by Google for deep learning and training massive neural networks.
- **PyTorch:** Developed by Facebook's AI team; highly popular in research due to its dynamic computation graphs and easy debugging.
- **Keras:** A high-level neural network API that acts as an easy-to-use interface running on top of TensorFlow.

**5. Web Development**

- **Django:** A "batteries-included", high-level full-stack framework that provides built-in tools for databases, authentication, and security.
- **Flask:** A lightweight micro-framework designed to be minimal, flexible, and easy to set up for smaller apps and microservices.
- **FastAPI:** A modern, high-performance web framework used specifically for building APIs quickly, complete with automatic data validation.

**6. Natural Language Processing (NLP) & Computer Vision**

- **NLTK (Natural Language Toolkit):** A classic library containing extensive datasets and text-processing tools for linguistic analysis.
- **spaCy:** Built for production-ready, advanced NLP tasks like entity recognition and text classification.
- **OpenCV:** The standard open-source library for computer vision, image processing, and real-time video analysis.
